You can use the Global Search Bar in the main header to search by project name or Project ID (e.g. PROJ-001). For granular filtering:

  • Navigate to the Projects Registry page.
  • Use the top filter bar to filter by Ministry, State, or Current Status (Ongoing, Delayed, Completed, Not Started).
  • Sort by approved cost, expenditure, or physical progress percentage.

The IIPMP automated risk engine evaluates projects using standard MoSPI parameters:

Risk Tier Criteria Breakdown
Low Risk On-schedule execution. Physical progress matches baseline expectation, and revised cost ≤ approved cost.
Medium Risk Timeline delay between 1–6 months or financial cost overrun between 1%–10%.
High Risk Timeline delay exceeding 6 months, severe physical progress gap (>25%), or cost overrun >10%.

Risk levels update automatically whenever new expenditure or physical progress data is logged.

  • Not Started / On Hold: Project approved or sanctioned, but ground excavation or physical work has not commenced.
  • Ongoing: Active construction or commissioning underway within scheduled parameters.
  • Delayed: Expected completion date has elapsed without 100% physical progress.
  • Completed: Physical assets commissioned and verified (100% progress).

IIPMP provides built-in report export tools:

  • Dashboard CSV Export: Click the Export Report button on the Dashboard page to download a full CSV breakdown.
  • Review Reports: Navigate to the Review Page for focused lists of delayed or high-cost overrun projects.
  • Print-to-PDF: Use standard browser print (Ctrl+P / Cmd+P) on any page — pages are optimized with clean print stylesheets.

Nodal officers and system admins can perform bulk uploads via the Database Management interface. Ensure your CSV file includes the following mandatory headers:

project_id,project_name,ministry,department,state,implementing_agency,approved_cost,revised_cost,expenditure,start_date,expected_completion,physical_progress,financial_progress,status,description

Dates must be formatted as YYYY-MM-DD. Cost values should be in numerical ₹ Crores without currency symbols or commas.

The IIPMP automated trigger engine monitors data entries in real-time. System alerts are generated when:

  • Revised cost exceeds approved budget.
  • Physical progress lags >20% behind expected target schedule.
  • Expected completion date passes while project is incomplete.
  • Milestone target dates are missed by implementing agencies.

Logged-in administrators can manage milestones directly:

  1. Open the specific project detail page (e.g. from the Projects list).
  2. Scroll down to the Milestones & Progress Timeline section.
  3. Click + Add Milestone or the Edit button next to an existing milestone.
  4. Update completion dates and set status to Completed, In Progress, or Pending.

Administrative credentials are reserved for designated Nodal Officers appointed by participating Ministries, Departments, and Implementing Agencies (e.g., NHAI, Indian Railways, CPWD). Submit an official access request via the Send Feedback tab or contact the MoSPI Data Informatics Division.
